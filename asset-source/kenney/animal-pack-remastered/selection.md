# MVP 素材選擇：Animal Pack Remastered

- 來源：[Kenney 官方素材頁](https://kenney.nl/assets/animal-pack-remastered)
- 授權：套件官方 `License.txt` 標示 Creative Commons Zero（CC0）；本檔案與原始 ZIP 保留在此資料夾。
- 視覺選擇：採用 `PNG/Round` 中圓形、彩色的動物插圖，使用單一插圖風格；卡片框與 UI 以 Phaser 圖形繪製，沿用插圖色彩，不加入風格不同的 UI 套件。
- MVP 使用：長頸鹿、企鵝、青蛙、樹懶、大象、貓頭鷹，共六張卡片。
- 執行時素材：只把這六個 PNG 放在 `public/assets/images/kenney/animal-pack-remastered/cards/`；完整原始套件留在 `asset-source/`，不會整套打包到遊戲輸出。
